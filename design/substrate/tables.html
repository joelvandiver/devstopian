Sticky header & first column

Scroll the table both ways — the header row and the Rack column stay pinned. The corner cell wins the z-stack.

<th data-sticky-col>…
<td data-sticky-col class="bg-inherit">…

Sortable headers

Add aria-sort="none" and a .ds-caret. data-sort-type="number" forces numeric ordering; state lives in aria-sort.

<th aria-sort="none"
    data-sort-type="number">

Truncation + tooltip

.ds-truncate ellipsises overflow; pair it with a native title for the full value on hover.

<td class="ds-truncate"
    title="full value">

Density variants

Set data-density on the table — compact (26px), default (32px), comfortable (42px) row heights.

<table class="ds-table"
   data-density="compact">

Zebra striping

Each row carries an opaque background so the sticky cell stays readable. Stripe with the even: variant.

<tr class="bg-surface
   even:bg-surface-sunken">

Horizontal scroll

Wrap the table in an overflow-auto container with a max-height to get both axes of scrolling and a contained sticky context.

<div class="overflow-auto"
  style="max-height:540px">
