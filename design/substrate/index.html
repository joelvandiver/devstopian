Substrate

A dense, token-driven design system for data center control planes — rack inventory, throughput dashboards, cooling telemetry and network topology. Built on Tailwind CSS v4 with a primitive → semantic token model, runtime light/dark theming, and predictable utility markup that small models can parse and extend.

Design tokens

Tokens are declared with Tailwind v4's @theme directive. Primitives generate static utilities; semantic tokens are CSS variables in :root / .dark, mapped to live utilities via @theme inline. Toggle the theme (top-right) to watch semantic tokens swap.
